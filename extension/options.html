Promptizer settings

Use Gemini Nano on-device first, with your existing Groq service as a configurable fallback.

The first download requires your click, an unmetered connection, supported hardware, and about 22 GB of free disk. Inference then runs inside Chrome. Supported prompt languages currently include English, Spanish, Japanese, German, and French.

Groq fallback pairing

Optional when Gemini Nano works. Run ./bin/promptrefine pair, then paste the revocable local token here to enable fallback.

Start the service with PROMPTREFINE_EXTENSION_ORIGIN set to this exact value.

Behavior

Inline suggestions wait for a meaningful pause and never submit. Press Tab to accept when the caret is at the end, or Esc to dismiss.

Local-first privacy boundary

Gemini Nano processes the current draft and selected context on-device. If Groq fallback is enabled and used, that same bounded input is sent to Groq. Promptizer does not collect the whole page or thread.
